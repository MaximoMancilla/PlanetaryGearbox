# PlanetaryGearbox
A two-stage planetary gearbox designed in Autodesk Fusion 360 with a theoretical 16:1 speed reduction.

Specifications
2 planetary stages
15T Sun Gear
15T Planet Gears
45T Ring Gears
Module: 2.25 mm
Pressure angle: 20°
3 planet gears per stage
Designed for desktop 3D printing
Files

The repository contains the CAD models and engineering drawings for the gearbox.
